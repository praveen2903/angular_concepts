what is best?

capability                    find()               aggregate()
Primary Purpose               Fetching           documentsTransforming 
data Output Type             Database Cursor      Database Cursor
Can Group Data?               No                   Yes ($group)
Can Join Collections?         No                   Yes ($lookup)
Can Create New Fields?        No                   Yes ($addFields)
Syntax Complexity           Simple & Concise     Verbose Array Pipeline


Performance Tip: 
While aggregate() can perfectly replicate everything find() does by using a standalone $match stage, you should default to find() for simple lookups. Because aggregate() converts BSON documents into internal objects for processing and shifts them back to BSON at completion, it carries a higher CPU/memory overhead for large datasets if no actual transformations take place.
