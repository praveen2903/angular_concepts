1. Interpolation {{ '{' }}{{ '{' }} {{ '}' }}{{ '}' }}

Displays TypeScript values inside HTML.

Example

Name : {{ name }}

Age : {{ age }}

Flow

TypeScript Variable
        ↓
Interpolation
        ↓
HTML Output

Common Traps

  • ❌ Avoid heavy function calls inside interpolation.
  • ❌ Cannot use loops or if statements.
  • ✅ Use only expressions.

2. Event Binding ()

Listens to browser events and executes TypeScript methods.

Examples

{{ count }}

Flow

User Click
     ↓
(click)
     ↓
increment()
     ↓
count++
     ↓
UI Updated

Common Traps

  • ❌ Too much logic inside templates.
  • ❌ Multiple function calls in click handler.
  • ✅ Keep logic in TypeScript methods.

3. Property Binding []

Updates DOM properties using component state.

Examples

[disabled]
[src]
[alt]
[min]
[max]
[value]

Flow

TypeScript
      ↓
Property Binding
      ↓
DOM Property

Common Traps

  • ❌ disabled="true"
  • ✅ [disabled]="isLoading"
  • ❌ Confusing attributes with properties.

5. Two-Way Binding [(ngModel)]

Synchronizes TypeScript and HTML automatically.

Typed Name : {{ name }}

Flow

TypeScript
      ↓
Input
      ↑
User Input

Behind The Scenes

[value]="name" + (input)="name=$event.target.value" = [(ngModel)]="name"
{{ngModelDemo}}

Common Traps

  • ❌ Forgetting FormsModule.
  • ❌ Mixing Template Forms and Reactive Forms.
  • ✅ Import FormsModule in AppModule.

6. Style Binding [style]

[class.xxx] and [style.xxx] are preferred when binding a single class/style. [ngClass] and [ngStyle] are preferred when multiple dynamic classes/styles. need to be applied together.

Dynamically applies inline CSS styles using component data.

Angular Style Binding

Flow

Component Variable
        ↓
[style.color]
        ↓
Inline CSS
        ↓
UI Updated

Examples

[style.color]
[style.background]
[style.font-size.px]
[style.width.px]
[style.display]

Common Traps

  • ❌ Too many inline styles.
  • ❌ Complex styling logic in HTML.
  • ✅ Use class binding for large styles.
