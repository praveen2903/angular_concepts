Traffic lights and ChangeDetectionRef usage

    
Q. Why did detectChanges() fix the issue?

A. currentIndex changed inside an async callback.
Angular did not run change detection for that update.
detectChanges() manually triggers a view refresh.

------------------------------------------------
Q. Can ngOnChanges() fix it?

A. No. As parent component change like that it manages you can see previously. Own state then ngonchange don't work.
ngOnChanges only runs for @Input changes from a parent component.
It does not run when a component updates its own state.
